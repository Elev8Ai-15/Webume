> Generated by LuxeCraft · Target: **Next.js** · Archetype: **Midnight Atelier**

## 1. Project Brief & Narrative
**Brand narrative**

Never rebuild your resume again. Careerory turns a resume into a living career profile: build it once, update it forever, share it as a link. Every job gets its own page with photos, numbers, and coworkers who vouch for you.

**Target emotions:** confidence, warmth, trust, pride

**Inspiration:** A career you're proud of, presented like it matters.

**Style direction:** Midnight Atelier — Deep ink canvas, maroon accents, and restrained motion. A private studio after hours — confident and quiet.

## 6. Motion Identity
One easing family, one duration scale, everywhere — motion reads as branded when it repeats. Never default `ease`.

### Mask Reveal
Spec: _headline lines rise from behind an overflow mask — 496ms quart-out, one line per 60ms_
```css
.lx-mask{display:block;overflow:hidden}
.lx-mask > *{display:block;transform:translateY(110%);animation:lx-rise 496ms cubic-bezier(0.25, 1, 0.5, 1) forwards}
.lx-mask:nth-child(2) > *{animation-delay:60ms}
.lx-mask:nth-child(3) > *{animation-delay:120ms}
@keyframes lx-rise{to{transform:translateY(0)}}
@media (prefers-reduced-motion: reduce){.lx-mask > *{animation:none;transform:none}}
```

### Stagger Cascade
Spec: _siblings fade up 12px in sequence — 347ms quart-out, 60ms apart, total under 1s_
```css
.lx-cascade > *{opacity:0;transform:translateY(12px);animation:lx-fade-up 347ms cubic-bezier(0.25, 1, 0.5, 1) forwards}
.lx-cascade > *:nth-child(2){animation-delay:60ms}
.lx-cascade > *:nth-child(3){animation-delay:120ms}
.lx-cascade > *:nth-child(4){animation-delay:180ms}
.lx-cascade > *:nth-child(5){animation-delay:240ms}
@keyframes lx-fade-up{to{opacity:1;transform:translateY(0)}}
@media (prefers-reduced-motion: reduce){.lx-cascade > *{animation-duration:1ms;transform:none}}
```

### Page Transitions (View Transitions API)
Spec: _cross-fade between pages, 336ms cubic-bezier(0.25, 1, 0.5, 1) — pure CSS, zero dependencies, MPA-capable._
```css
@view-transition { navigation: auto; }
::view-transition-old(root), ::view-transition-new(root) {
  animation-duration: 336ms;
  animation-timing-function: cubic-bezier(0.25, 1, 0.5, 1);
}
@media (prefers-reduced-motion: reduce) {
  ::view-transition-old(root), ::view-transition-new(root) { animation: none; }
}
```

### Magnetic Button
The CTA leans toward the cursor inside a 90px radius and springs home when it leaves. Desktop pointers only; inert under reduced motion. Use on ONE button per view.

```html
<span class="lx-magnet-zone" style="display:inline-block"><button class="lx-magnet" style="display:inline-flex;align-items:center;gap:8px;border:0;border-radius:10px;background:#d95a6b;padding:14px 28px;font:500 15px/1 Manrope, 'Segoe UI', system-ui, sans-serif;letter-spacing:.02em;color:#12100e;box-shadow:0 6px 16px -2px rgba(0,0,0,0.15), 0 3px 8px -1px rgba(0,0,0,0.28), 0 1px 2px rgba(0,0,0,0.14);cursor:pointer;transition:transform .18s ease-out">Drawn to you</button></span>

(function(){
```

### Custom Cursor
A dot with a trailing ring (lerp-smoothed) that grows over links and buttons; mix-blend-difference keeps it visible on any surface. Native cursor stays available; hidden entirely on touch devices. Paste once, site-wide.

```html
<style>
.lx-cursor-dot,.lx-cursor-ring{position:fixed;top:0;left:0;border-radius:50%;pointer-events:none;z-index:9999;mix-blend-mode:difference}
.lx-cursor-dot{width:6px;height:6px;background:#fff}
.lx-cursor-ring{width:34px;height:34px;border:1px solid #fff;transition:width .25s ease,height .25s ease}
@media (pointer:coarse){.lx-cursor-dot,.lx-cursor-ring{display:none}}
</style>
<script>
(function(){
  if(!matchMedia('(pointer:fine)').matches)return;
  if(document.querySelector('.lx-cursor-dot'))return; /* idempotent: pasted twice = one cursor */
  var d=document.createElement('div');d.className='lx-cursor-dot';
  var g=document.createElement('div');g.className='lx-cursor-ring';
  document.body.append(d,g);
  var x=innerWidth/2,y=innerHeight/2,rx=x,ry=y,running=false;
  function loop(){
    rx+=(x-rx)*0.14;ry+=(y-ry)*0.14;
    g.style.transform='translate('+rx+'px,'+ry+'px) translate(-50%,-50%)';
    /* idle when the ring has caught up — no permanent 60Hz tick */
    if(Math.abs(x-rx)+Math.abs(y-ry)>0.2){requestAnimationFrame(loop);}else{running=false;}
  }
  addEventListener('mousemove',function(e){x=e.clientX;y=e.clientY;
    d.style.transform='translate('+x+'px,'+y+'px) translate(-50%,-50%)';
    if(!running){running=true;requestAnimationFrame(loop);}});
  document.querySelectorAll('a,button').forEach(function(el){
    el.addEventListener('mouseenter',function(){g.style.width='52px';g.style.height='52px';});
    el.addEventListener('mouseleave',function(){g.style.width='34px';g.style.height='34px';});
  });
})();
</script>
```

## 8. Micro-Interaction Specs
- **Button hover:** brightness +10%, `144ms cubic-bezier(0.25, 1, 0.5, 1)`. No scale bounce.
- **Card entrance:** fade + 12px rise, `496ms cubic-bezier(0.25, 1, 0.5, 1)`, staggered 60ms.
- **Focus ring:** 2px accent ring, 2px offset, appears on `:focus-visible` only.
- **Depth tilt:** on hover, `perspective(1200px) rotateX(4deg) translateZ(8px)` — subtle, never a gimmick.
- **Reduced motion:** all of the above collapse to opacity-only (and flat, no tilt) under `prefers-reduced-motion`.

## 9. Finish Checklist (apply everywhere)
- Section padding is generous: 120–200px desktop verticals. Whitespace IS the luxury.
- Eyebrow labels above every section heading: numbered, UPPERCASE, tracked .18–.28em.
- Hairline 1px rules at low opacity structure lists — prefer them over boxed card grids.
- One border-radius language site-wide. One accent color, used sparingly.
- Custom `::selection` background (use Primary at ~30% over #0b1020).
- **Remove these cheap tells:** default `ease` easing, pure #000/#fff, more than 2 fonts, hard single shadows, tight section padding, instant no-transition hovers.
- Every animation respects `prefers-reduced-motion` (all snippets above already do).
