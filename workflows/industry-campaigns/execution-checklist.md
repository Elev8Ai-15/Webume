# Campaign Execution Checklist
## Use this to track campaign launch and weekly execution

---

## PRE-LAUNCH SETUP
- [ ] Record HeyGen video templates for each industry
- [ ] Set up email sequences in CRM/email tool with merge fields
- [ ] Prepare Revenue Leak Calculator with industry-specific defaults
- [ ] Build prospect lists from Local Targeting sources in each playbook

## WEEKLY EXECUTION CADENCE
- **Monday**: Pull 20 new prospects (mix of industries) from targeting sources
- **Tuesday**: Send personalized cold emails (batch of 20)
- **Wednesday**: Record HeyGen videos for top 5-10 highest-value prospects
- **Thursday**: LinkedIn DMs to the same batch + engage with their content
- **Friday**: Review responses, schedule follow-ups, update pipeline

## CAMPAIGN METRICS TO TRACK
| Metric | Target |
|--------|--------|
| Emails sent per week | 20 |
| HeyGen videos sent per week | 5-10 |
| LinkedIn DMs per week | 20 |
| Email open rate | 40%+ |
| Email reply rate | 5-8% |
| HeyGen video view rate | 60%+ |
| Meetings booked per month | 8-12 |
| Clients closed per month | 3 |

## PROSPECT PRIORITIZATION (Score each prospect)
1. **Website quality** (lower = more opportunity): Does their site have chat? ADA issues? Mobile-friendly?
2. **Review volume and rating**: Active businesses with review gaps are ideal
3. **Ad spend signals**: Running Google Ads = already investing in leads, will value better conversion
4. **Business size**: 5-50 employees is the sweet spot
