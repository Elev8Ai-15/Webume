# Document Output Skill

## When to use
- Brad needs a proposal, report, or professional document
- Raw notes or research need to become a client-ready deliverable
- Any output that will be shared externally or kept as a record

## Process
1. **Gather inputs**: Collect all notes, research, and context
2. **Confirm format**: Ask Brad what type of document (proposal, report, memo, etc.) if unclear
3. **Draft**: Write the document using the appropriate template below
4. **Review**: Run through ops-quality-critic for anything client-facing
5. **Deliver**: Save to outputs/ folder

## Document types

### Proposal
- **Header**: Elev8 AI Solutions & Services
- **Sections**: Executive Summary, Problem Statement, Proposed Solution, Deliverables & Timeline, Investment, Next Steps
- **Tone**: Professional, confident, benefit-focused

### Report
- **Sections**: Summary, Background, Findings, Analysis, Recommendations
- **Tone**: Objective, data-driven

### Memo / Internal doc
- **Sections**: Purpose, Key Points, Action Items
- **Tone**: Direct, concise

## Rules
- Always include Brad's business name: Elev8 AI Solutions & Services
- Professional formatting: clear headings, consistent structure
- Include a clear call-to-action or next steps
- Proofread for grammar, spelling, and consistency
- Save to outputs/ folder with descriptive filename
