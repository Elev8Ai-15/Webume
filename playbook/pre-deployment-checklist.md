# Pre-Deployment Checklist — Elev8 AI Agent Swarm

Use this checklist before starting any client installation. All items must be checked off before proceeding to setup.

---

## Business Prerequisites

- [ ] Contract signed and setup fee collected
- [ ] Tier confirmed: Self-Serve or Managed
- [ ] Monthly billing date agreed

---

## Client Information (collect during discovery call)

- [ ] Business name
- [ ] Owner/contact name and email
- [ ] Business address and service area
- [ ] Industry vertical
- [ ] Services offered (with pricing if available)
- [ ] Business hours and emergency availability
- [ ] Communication tone preference (e.g., "friendly and professional", "casual and approachable")
- [ ] Timezone

---

## Tool Access (client provides)

- [ ] Gmail: OAuth app password or token created (NOT raw password)
- [ ] Google Calendar: access confirmed
- [ ] Google Drive: access confirmed (if needed)
- [ ] Stripe or QuickBooks: API key or OAuth token (if applicable)
- [ ] Any other tools client uses (Notion, CRM, etc.)

---

## Technical Requirements (Self-Serve only)

- [ ] Client machine: modern Windows/Mac, 8GB+ RAM, stable internet
- [ ] Claude Code installed on client machine
- [ ] Client has Claude Max subscription (~$100/mo)
- [ ] Client comfortable with basic CLI interaction (or willing to learn in 2hr training)

---

## Technical Requirements (Managed only)

- [ ] Brad's access to client email/calendar/drive confirmed
- [ ] NDA signed for data access
- [ ] Delivery channel agreed (email, Notion, Slack — where Brad sends outputs)

---

## Security

- [ ] All credentials are OAuth tokens or app passwords (no raw passwords)
- [ ] Credential storage location prepared (encrypted vault)
- [ ] Access limited to Brad only
