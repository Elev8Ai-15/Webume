## 1. Service Description

Provider will deploy a customized AI agent swarm for Client's business operations using Claude Code by Anthropic. The swarm consists of AI agents configured to assist with daily business tasks including but not limited to: email management, scheduling, lead qualification, content drafting, and customer communications.

**Selected Tier**: ☐ Self-Serve Swarm | ☐ Managed Swarm

---

## 2. Scope of Work

### Self-Serve Swarm ($5,000 setup + $500/month)
- Deployment of 3-5 AI agents customized for Client's business
- Configuration of business skills and memory system
- Connection of up to 4 MCP integrations (Gmail, Calendar, Drive, +1)
- 2-hour training session on Claude Code usage
- Client receives full control of their deployment

**Monthly includes**:
- 1 check-in call per month
- 1 new agent or skill added per month
- Email support (48-hour response time)

### Managed Swarm ($10,000 setup + $1,500/month)
- Deployment of 8-12 AI agents customized for Client's business
- All skills, custom workflows, and full memory system
- Connection of all available MCP integrations
- Provider operates the swarm on Client's behalf

**Monthly includes**:
- Provider operates all agents and delivers outputs weekly
- API costs included (no additional charges)
- 2 new agents or skills added per month
- Priority support (24-hour response time)
- Weekly deliverables (content drafts, email responses, reports)

## 3. Client Responsibilities

### Both Tiers:
- Provide accurate business information during discovery
- Grant necessary account access (Gmail, Calendar, etc.) via OAuth tokens or app passwords
- Review and approve all external-facing content before it is sent or published
- All business decisions made using agent outputs are Client's sole responsibility
- Respond to Provider communications within 5 business days

### Self-Serve Only:
- Maintain an active Claude Max subscription (~$100/month, Client's own account)
- Operate and interact with Claude Code directly
- Report issues via email to Provider

### Managed Only:
- Provide timely feedback on weekly deliverables
- Approve outputs requiring Client action within 48 hours

## 5. Data Handling & Security

a) **Local deployment**: All agent configurations, memory files, and business data reside on Client's local machine. Client owns all data.

b) **Managed tier access**: Provider accesses Client systems solely for the purpose of operating the agent swarm. Access is governed by the NDA attached as Exhibit A.

c) **API processing**: Agent interactions are processed through Anthropic's Claude API. Data sent to the API is subject to Anthropic's data usage policies (https://www.anthropic.com/policies).

d) **No third-party sharing**: Provider will not share, sell, or transfer Client data to any third party, except as required by law.

e) **Credential security**:
   - All credentials stored using OAuth tokens or app passwords (never raw passwords)
   - Credentials stored in encrypted vault, not plaintext files
   - Access limited to Provider only — no shared drives or unencrypted backups
   - Provider will notify Client within 24 hours of any suspected credential compromise

c) **Upon termination**:
